# Research Synthesis

Separate retrieval value from the Writer's ability to answer. Request another
round only for an important, concrete, researchable gap in the user's core
request. Treat verified claims as optional citation material rather than a
closed knowledge boundary. The Writer may add knowledge and analysis without a
claim ID. When a claim ID is used, use only a supplied ID and keep the citation's
scope faithful to its evidence; never attach a claim to unrelated prose.
