## 参数与选择依据

将依据分成已做对照、沿用协议与工程预算。以下参数并非全部经过网格搜索。

| 参数 | 当前值 | 依据 |
|---|---|---|
| Embedding | thenlper/gte-small-zh 512维 | 旧固定语料模型对照中，真实文档纯向量Hit@5：E5 34.7%、BGE-small-zh 56.9%、GTE 66.7%；本轮GTE结果复现。只说明这组资料适配性 |
| Embedding revision | af7bd46fbb00b3a6963c8dd7f1786ddfbfbe973a | 固定实验模型，不随远程分支漂移；与已有索引身份一致 |
| 索引 | FLAT＋COSINE 归一化向量 | 当前只有数百切片，用精确扫描避免近似索引误差；没有大规模ANN吞吐结论 |
| 切片上限 | 约600字符 | 原有结构切片工程起点，优先段落/章节/表格行；不是600 Token，也未做长度扫描证明最优 |
| BM25 | k1=1.2 b=0.75 | 沿用现有实现常用取值，没有在本项目做系统网格搜索 |
| 两路召回数 | BM25 20 向量40 | 沿用飞书方案及冻结实验协议，固定候选开销；并非已证明最优TopK |
| RRF k | 60 | 沿用排名融合协议，避免直接相加两路分数；本轮已展示其局限，没有做k扫描 |
| 候选配额 | quota_dense 四分之一关键词 四分之三向量 | 原配额对照支持偏向语义路；本轮无精排阶段命中48→49/72。共享候选去重后再补齐 |
| 重排池 | max(20,2×返回条数) | 单查询Top5实验池20；Worker每查询返回20，实际池40。是运行预算，不把两种调用当成完全相同 |
| 背景增强 | 固定的切片说明缓存 | 本轮命中49→67/72；说明绑定全文与切片哈希，只增强索引，不进入最终引用原文。新文档没有缓存则回退普通索引 |
| 标题章节统一前缀 | contextual_index=false | 旧对照中仅加元数据前缀没有稳定收益，当前使用切片级说明；表格表头保留不受此开关影响 |
| Reranker | BAAI/bge-reranker-v2-m3 | 旧背景增强后模型对照：MiniLM MRR0.832，BGE原文0.877；本轮真实执行后复现0.877 |
| Reranker revision | 953dc6f6f85a1b2dbfca4c34a2796e7dde08d41e | 固定模型权重，降低结果漂移 |
| 运行设备及输入长度 | CPU 最大512 Token | 与冻结精排实验一致；限制每对输入计算量。长输入可能截断，并不保证任意600字符切片加长查询都完整进入模型 |
| 相邻原文精排 | 0字符 | 旧BGE相邻原文实验Hit更高但MRR下降至0.817且更慢；本次优先首位排序，保留原文精排 |
| 查询改写 | false | 旧同条件对照中rewrite RRF Hit@5由88.9%降至86.1%，且增加调用耗时；未证明新模型一定同样下降，本次暂不启用 |
| 单次精排超时 | 30秒 | 沿用既有BGE实验预算，给本地冷加载/40候选留余量；本次常规Top5检索P95约3.48秒，不是30秒最优的证明 |
| Worker总检索超时 | 90秒 | 为最多4条任务查询与回源留总预算，同时限制RAG拖延研究；属于工程约束，不能保证每条查询各跑满30秒 |
| 任务查询数 | 最多4条 每条最多300字符 | 原实现的有界任务投影，避免检索调用随问题长度无限增长；不是本次调参所得 |
| 最终上下文段数 | 默认3 | 控制Worker上下文成本的保守起点，没有证明Top3最优；94.4%是Top5实验分数，不是实际Worker Top3成绩 |
| 每来源上限 | 2段 | 防止同一文档挤满上下文，兼顾多子问题/多来源；工程预算，本次未扫描最优值 |
| 上下文包上限 | 6000字符 | 包含原文及元数据的序列化字符数，不是6000 Token；本次实际2528字符 |
| 自动保存抓取资料 | persist_fetched_sources=false | 本次启用资料检索与重排，没有同时打开网页自动沉淀。已有研究作用域机制仍可独立启用 |
| 本地并发写入 | 统一URI namespace 锁目录 | 同机进程锁，不是分布式锁；精排器单实例忙碌或超时时仍会回退RRF，本次未做多Worker并发负载评测 |
