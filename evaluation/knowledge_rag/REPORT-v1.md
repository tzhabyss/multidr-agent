# 本地研究资料 RAG 开发评测

日期：2026-10-19。模型：`sentence-transformers:intfloat/multilingual-e5-small`，`degraded=false`。本次实际执行了本地 E5 模型，无托管 LLM 调用。

## 检索结果

语料为当前 README.md、docs/model-modes.md、docs/mcp.md 三份文档，12 条人工标注的中英文问题。原文标签是精确证据跨度，未将问题注入文档。模型／参数未按这些问题调优；此集合仍属于开发集。

| 方法 | 全库证据 Recall@5 | 全库 MRR@5 |
|---|---:|---:|
| BM25 | 58.3% | 0.326 |
| E5 向量 | 75.0% | 0.544 |
| BM25＋E5＋RRF | 83.3% | 0.519 |

融合改善了本集 Recall@5，但 MRR 低于纯向量，不能说所有排序指标都改善。

## 原文窗口对照

此项已知正确文档，比较当前 `_focused_extraction_windows`（无命中时使用现有首部窗口回退）和 RAG Top3 加邻接段回填。

| 方法 | 完整证据跨度命中率 | 平均上下文字符 |
|---|---:|---:|
| 当前关键词窗口／首部回退 | 100.0% | 6022 |
| RAG 原文回填 | 91.7% | 1776 |

候选上下文减少约 70.5%，但完整跨度命中下降，不能直接替换掉旧窗口。生产集成保留原窗口回退，实际输入 Token 是否减少取决于抽取是否成功和回退调用次数。本次没有测 API Token、费用或最终报告质量。

索引耗时约 5.84 秒（含模型加载），BM25 查询均值 3.9ms，向量查询 37.6ms，混合查询加原文窗口回填 55.2ms。计时工作量不同，只作本机诊断，非严格延迟对照。

## 降级与功能检查

哈希降级的初次开发检查表现较差，因此实现已改为 E5 不可用时只使用 BM25；最终降级结果单独存档，不混入真实语义模型结果。

本次相关自动化测试共 109 项通过（含原有 CLI、配置、抽取与证据安全回归）。导入／检索／重建命令也完成独立冒烟检查。

功能测试覆盖：持久化／判重、collection 隔离、精确原文位置、版本发布失败保留旧版、历史快照、内容篡改校验、重排失败回退、并行重复导入、重排超时不堆积，以及完整 FakeLLM 研究流程中的本地来源与 RAG 抽取记录。FakeLLM 集成只证明连接和证据链工作，不证明真实模型回答质量。

## 结论与后续评测

本集支持保留 RAG 作为取证候选层，尚不支持宣称最终回答更准确。需要真实用户论文／年报、更多中英文及跨段／表格问题、独立盲测集，并测实际抽取 Token、证据覆盖、引用正确率及端到端耗时。重排、OCR、复杂表格和业务生效日期不在本轮收益评测内。
